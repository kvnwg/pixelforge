# Example exports

Finished pixelforge exports, regenerated by `tools/make_examples.py` (run `pf build --all` and `pf fx build --all` first). Each character is a PNG spritesheet plus Aseprite-format JSON with combat data in `meta.pixelforge`, and one GIF to look at. Load them with the code in `loaders/` (see the README at the repo root).

| Character | Rig | Size class | Pivot | Timing | What it shows | Animations |
|---|---|---|---|---|---|---|

| [`rk_ranger`](rk_ranger/) | humanoid | small | [15, 27] | player | a Rolling Knight class: bow, backflip | 12 |
| [`slime`](slime/) | blob | small | [15, 27] | enemy | blob rig: squash and stretch, hop, spit | 7 |
| [`bat`](bat/) | flyer | small | [15, 27] | enemy | flyer rig: hovers over a grounded pivot | 6 |

| [`goblin_archer`](goblin_archer/) | humanoid_small | small | [15, 27] | enemy | humanoid_small rig: a goblin archer on the enemy profile | 7 |

`fx/`: the FX library, 44 effects, each a sheet plus JSON with its pivot per tag (`<anim>_<dir>`), layer, space and loops; `fx/index.json` lists them.
